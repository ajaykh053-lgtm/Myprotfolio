Hacker House Goa ID Generator

An elite, high-performance web application built for Hacker House Goa 2026 in partnership with 1:47 PM Studio. The platform provides participants and builders with a lightning-fast, zero-friction tool to generate official, customized Goa-themed hacker ID badges and shareable social media frames instantly.

The application features instant client-side canvas rendering that generates high-resolution professional badges in milliseconds without any server latency or loading screens. It includes advanced photo upload capabilities supporting JPEG, PNG, and HEIC formats, paired with real-time zoom scale and horizontal/vertical pan sliders to perfectly frame any portrait, landscape, or off-center selfie.

Participants can fully customize their hacker identity by tailoring their full name, role, technical stack, builder track, and auto-generated unique builder IDs. The visual design incorporates an authentic Goa tropical theme with vintage postal stamps, sunburst avatar framing, and a rich sunset beach footer complete with coconut palm silhouettes, flying seagulls, and beach loungers.

For seamless sharing, the platform provides one-click PNG downloads and direct X (Twitter) sharing integration with pre-filled promotional captions and the mandatory #FrameInGoa hashtag. Built with React 19, TypeScript, Tailwind CSS, HTML5 Canvas API, and Radix UI.
